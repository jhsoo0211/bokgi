## 3. 확인한 사실

- Tiingo 무료 플랜: 내부·개인 용도만. 화면 표시·재배포는 별도 라이선스(유료, 출처 표기 의무). Twelve Data 개인 플랜: 내부 용도만, 외부 사용자에게 표시하려면 유료 플랜과 추가 계약.
- 금융위원회 주식시세정보(공공데이터포털): 이용허락범위 "제한 없음". 출처 표기 권장.
- IfSave에서 가져올 조각은 작고 순수하다: 숫자 발화 제한(약 180줄), 시장 국면 판정(24줄), 실력·운 사분면(15줄), OpenAI 호환 호출·폴백 계층. IfSave에는 익명화 결정 기록이 없고, 연구 저장소에 익명화·식별 점검·시점 특징 도구가 있다.
- 워크시트 프로토타입의 실제 값: 리포트 잠금 10장, 확신도 기본값 3, 되돌리기 2.5초 뒤 자동 공개, 디자인 문서가 참조하는 SwipeCard README 없음.
