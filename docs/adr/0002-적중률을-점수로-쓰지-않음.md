# ADR-0002 적중률을 점수로 쓰지 않는다

- 상태: 채택 (2026-10-03)
- 관련: `CONTEXT.md`의 '결과 상태', '일지', '통계', '스트릭'

## 맥락

6개월 주가 방향의 절반 가까이는 시장 흐름과 우연으로 설명된다. 적중률을 점수로 올리면 사용자는 근거 대신 운을 연습하고, 서비스는 '주가 맞히기 게임'으로 읽힌다. 그러나 아무 피드백도 없으면 돌아올 이유가 없다. 듀오링고식 습관 장치는 쓰되 적중 경쟁은 쓰지 않는다는 선이 필요했다.

## 결정

1. 결과는 **세 상태**(시장보다 앞섬 / 뒤짐 / 비슷함 ±1%p)로 읽고, 비슷함은 적중·실패로 세지 않는다.
2. 적중 여부는 저장하되 **큰 숫자·랭킹·연승·배지로 보여 주지 않는다.**
3. 진행감은 **일지**(판단 기록, 즉시)와 **숙련도**(개념 상태)와 **스트릭**(연습한 날)으로 준다.
4. **통계는 20장이 쌓인 뒤**, 일지 안의 접힌 영역에, 글로 적는다("확신도 5를 준 판단 6번 중 시장보다 앞선 것은 2번").

## 대안

- 적중률을 보이되 작게 — 작아도 숫자는 비교를 부른다. 거절.
- 아무 통계도 없음 — 확신도 보정은 배울 가치가 있는 개념이다. 20장 뒤 글로 제공.
- 리그·주간 경쟁 — 사용자 확보에 도움이 되지만 서비스 정의와 충돌한다. 3단계에서도 '개념 이해'에만 붙일 수 있고 적중에는 절대 붙이지 않는다.

## 결과

- 베타의 재방문은 스트릭과 세션 끝맺음에 의존한다. 효과가 약하면 세션 구성을 바꾸되 적중 경쟁으로 돌아가지 않는다.
- 데이터 모델에서 `hit`은 `even`일 때 null이다. 집계 코드는 null을 제외한다.
