# ADR-0004 가벼운 마스킹: 식별을 막지 않고 근거를 먼저 세우게 한다

- 상태: 채택 (2026-10-03)
- 관련: `CONTEXT.md`의 '마스킹', '아는 회사 체크'

## 맥락

역사적으로 의미 있는 사례(금리 인상기 성장주, 팬데믹의 항공주)는 당시 시장 상황을 보여 주는 순간 회사와 시기가 짐작된다. 강한 마스킹(연도·업종 숨김, 상황을 추상화)은 식별을 어렵게 하지만 「그때」 판의 학습 가치를 없애고 카드 제작을 어렵게 한다. 원본 기획은 "브랜드·사전 지식 대신 제공된 정보를 읽게 하는 것"이 목적이라고 이미 적고 있다.

## 결정

1. 판단 전에 숨기는 것은 **회사 이름·티커·고유 제품명·정확한 날짜·판단 시점 이후의 모든 것**이다. 연도·업종·규모 구간·시장 상황은 보여 준다.
2. 판단 전에 **"이 회사를 아는 것 같아요"** 체크를 둔다. 체크는 판정에 쓰지 않고, 일지에서 아는 판단과 모르는 판단을 구분한다.
3. 마스킹 품질 검사는 **'결과 유출 없음'**(판단 시점 이후 정보·수치·사건이 없음)에 집중한다. 회사 식별률은 기록만 한다.
4. 질문자 AI에게는 회사 이름을 주지 않는다. 식별이 쉬운 카드라도 AI가 이름을 말하면 누수로 처리한다.

## 대안

- 강한 마스킹 — 「그때」 판과 충돌, 제작 비용 증가. 거절.
- 마스킹 없음 — 결과를 아는 사용자가 많아 판단 연습이 되지 않는다. 거절.

## 결과

- 식별된 카드에서도 근거 선택·확신도·세 상태 결과는 그대로 학습 신호다.
- 식별률이 매우 높은 카드는 난이도 표기를 낮추거나 중형주·국내 카드로 균형을 맞춘다.
