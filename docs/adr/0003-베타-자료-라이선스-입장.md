# ADR-0003 베타의 가격 자료는 파생 지수만 표시하고, 공개 전에 라이선스를 결정한다

- 상태: 채택 (2026-10-03) · **재검토: 베타 피드백 뒤, 공개 출시 결정 전**
- 관련: `01_기획안_v1.0.md` §11, `00_결정기록.md` D7·D14

## 맥락

복기 카드는 미국 대형주·역사적 사례를 쓴다. 가격 자료의 무료 API(Tiingo, Twelve Data)는 **내부·개인 용도만** 허용하고, 다른 사용자에게 보이는 표시·재배포는 별도 유료 라이선스 영역이다(2026-10-03 확인). 재무 수치는 공시 원문, 금리·거시는 중앙은행·통계 공개 자료로 라이선스 문제가 없다. 국내 금융위 시세는 공공데이터로 이용허락 제한이 없다.

## 결정

1. 초대 베타(비공개, 지인 10명)에서는 가격 흐름과 결과 경로를 **수작업 카드의 파생 지수(판단 시점 100 기준 14점)**로만 표시한다. 원시 가격·거래량 값은 표시하지 않는다. 카드에 원천 종류를 표기한다.
2. 재무·금리·이슈는 공개 자료(공시·통계·보도)로 만든다.
3. 국내 카드는 공공데이터를 쓰고 출처를 표기한다.
4. **공개 출시 전**에 가격 자료 라이선스를 결정한다: 유료 표시 라이선스(견적·조건을 적는다) 또는 다른 공급원. 구매는 별도 승인.
5. 연구 저장소의 채택 가격 자료(Twelve·KIS·Tiingo)는 **제작 도구의 계산 입력과 검증에만** 쓰고 화면에 내지 않는다.

## 대안

- 지금 유료 데이터 구독 — 사용자 10명 베타에 월 비용이 든다. 공개 결정 뒤로 미룬다.
- 국내 종목만으로 베타 — 라이선스는 깨끗하지만 '미국 대형주·역사적 사례' 요구와 충돌한다. 보조 트랙으로만.
- 원시 가격을 그대로 표시 — 무료 플랜 약관 위반. 거절.

## 결과

- 베타 카드의 흐름 판은 14점 지수라 세밀한 차트 분석이 불가능하다. 이는 '패턴을 정답처럼 가르치지 않는다'는 원칙과 맞는다.
- 파생 지수도 약관상 회색지대일 수 있음을 인지한다. 베타를 비공개·소수로 유지하는 이유다.
