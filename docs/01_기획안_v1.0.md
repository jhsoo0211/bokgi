> **한 줄 정의**

## 1. 문제 인식

1. 금융 생활은 시작됐지만 **정보를 읽고 자기 판단으로 연결하는 경험**이 없다. 뉴스·숫자를 보고도 "그래서 어떻게 봐야 하지"에서 멈춘다.
2. 기존 금융 교육은 **읽기 → 퀴즈 → 다음 글**의 수동 구조다. 판단을 요구하지 않으니 판단력이 늘지 않는다.
3. 차트 맞히기 게임은 **가격 패턴만** 다루고, 틀렸을 때 무엇을 배워야 하는지 알려 주지 않는다.
4. '대가 포트폴리오'는 따라 사기 소재로 소비되고, **왜 그때 그 선택을 했는지** 훈련하는 경험은 없다(2단계 역추적의 문제 인식).

복기는 이를 `실제 사례 → 내가 먼저 판단 → 결과·근거 확인 → 개념 학습 → 다음 사례에 적용`으로 바꾼다.

## 2. 누구를 위한 것인가

- **1차(베타):** 작성자 본인과 초대한 지인 10명. 투자 경험이 적거나, 뉴스·실적을 읽어도 판단으로 연결하지 못하는 20~30대.
- **2차:** 금융 교육을 '게임'이 아니라 '연습'으로 받아들이는 학습자. 교실 모드(3단계)의 교사·학생.
- **아닌 사람:** 실시간 매매 도구, 종목 추천, 수익률 경쟁을 원하는 사람.

성공은 사용자 수가 아니라 **매일 세션을 스스로 열게 되는가**로 본다(`00_결정기록.md` D6).

## 3. 유사 서비스와 차별점

| 유형 | 사례 | 겹치는 점 | 복기와의 차이 |
|---|---|---|---|
| 가려진 차트 방향 맞히기 | ChartGame, Chart Challenge, Chart Guess, 차트야 놀자 | 마스킹 → 판단 → 공개 | 가격 패턴만, 틀린 뒤 배울 개념이 없음 |
| 스와이프 종목 탐색 | Tickup, Prophit | 스와이프 + 학습 팁 | 현재 종목 '발견' 용도, 과거 사례 판단이 아님 |
| 금융 마이크로러닝 | Zogo, Fingo, Finelo | 개념 학습·일일 세션 | 콘텐츠 → 퀴즈. 판단이 없음 |
| 대가 포트폴리오 추적 | WhaleWisdom, Stockcircle, 치킨스탁 | 기관 보유 공개 | 무엇을 샀나만(2단계 역추적이 '왜'를 다룸) |
| AI 대가 챗봇 | BuffettBot, KeepRule | 투자자 철학 대화 | 질문 응답 도구, 판단 훈련 없음 |
| 익명 재무 판단 교육 | Ivey 'The Game of Financial Ratios' | 기업명 가린 재무 판단 | 경영대 수업용, 앱 아님 |
| 투자 회고 | Hedge(주식 투자 회고 서비스, 2025) | 판단을 원칙과 대조하고 '유지할 것 / 고칠 것'으로 피드백 | 자기 실제 매매를 사후에 회고. 복기는 결과를 모르는 과거 사례로 **먼저** 판단을 연습하고, 실거래 입력이 없다 |
| 스와이프 소비 평가 | SLAP(스와이프로 끝내는 가계부, 2025) | 스와이프 한 번으로 평가, 달력에 쌓임, 패턴 인사이트 | 소비 만족/후회 평가. 복기는 시장 대비 판단과 개념 학습 |

**닮지 않기:** 복기의 중심은 투자 **학습**이다. 유사 서비스에서 빌리는 것은 표현 장치(스와이프 리듬, 연습 달력, 한 줄 인사이트, 두 묶음 피드백)뿐이고, 그들의 중심(소비 평가, 실거래 회고, 상품 추천)은 가져오지 않는다. 화면마다 주인공은 카드·개념·기록이다(`06` §9 '닮지 않기 위한 경계').

**차별 지점:** ① 가격·재무·당시 상황을 **한 카드에서** 판단 소재로 쓴다 ② 결과를 **시장 대비 세 상태**로 읽는다 ③ 근거·확신도를 기록하고 **적중률 대신 판단의 질**을 본다 ④ 결과 뒤 **개념을 연결하고 간격을 두어 복습**한다 ⑤ '아는 회사'인지 스스로 표시해 **사전 지식과 판단을 분리**한다.

> 경쟁 우위는 마스킹이 아니라 **무엇을 판단하게 하고, 틀린 뒤 무엇을 가르치느냐**에 있다.

## 4. 학습 루프

`Observe → Judge → Reveal → Learn → Apply → Reflect`

1. **Observe:** 판단 시점까지의 정보(세 판)만 본다.
2. **Judge:** 핵심 근거 1개와 확신도를 고르고 시장 대비 방향을 정한다.
3. **Reveal:** 회사·기간·결과 상태·가격 경로를 본다.
4. **Learn:** 이 사례의 개념 1개와 확인 문제 1개.
5. **Apply:** 다음 카드와 복습 문제에서 같은 개념을 다시 쓴다.
6. **Reflect:** 일지에서 근거·확신도·결과의 관계를 본다. 통계는 20장 뒤.

## 5. 카드

### 5.1 세 판

| 판 | 보여 주는 것 | 연결되는 개념 |
|---|---|---|
| **흐름** | 판단 시점을 100으로 둔 가격 지수와 시장 지수(14점), 거래량 추이 | 추세·모멘텀·변동성·평균회귀·기저확률과 노이즈 |
| **숫자** | 성장(매출·영업이익률·EPS·가이던스), 밸류에이션(PER과 업종 중앙값·PBR·PSR), 건전성(부채비율·순현금·현금흐름·이자보상) | 성장 대 밸류에이션, 이익의 질, 현금흐름, 부채 |
| **그때** | 기준금리와 방향, 환율·원자재 메모, 업종·시장 이슈(판단일 기준 상대 날짜 + 출처 종류) | 금리와 할인율, 인플레이션, 업종 사이클, 이벤트 |

- 세 판은 모두 열어 볼 수 있다. 기본으로 열리는 판은 「숫자」. 어떤 판을 얼마나 봤는지는 기록만 하고 점수에 쓰지 않는다.
- 「흐름」은 패턴을 정답처럼 가르치지 않는다. 기저확률과 노이즈 개념이 반드시 따라붙는다.
- 「그때」의 문장은 사람이 템플릿으로 쓴다(LLM 생성 금지). 날짜는 상대 날짜, 출처는 종류(공시·보도·통계)로 적고 공개 뒤 원문 위치를 보여 준다.

### 5.2 정보 제공 원칙

1. 판단 시점에 알 수 있었던 정보만. 이후 정정치·컨센서스 변화·사후 기사는 없다.
2. 모든 카드가 같은 틀을 쓴다. 없는 값은 "데이터 없음 / 당시 미공개".
3. Core(판 요약)와 More(펼쳐 보기)를 나눈다.
4. 판단 전에는 절대 날짜를 쓰지 않는다. "판단일 D-30"처럼 상대 날짜만.

### 5.3 마스킹 — 가벼운 마스킹

| 숨기는 것 | 보여 주는 것 |
|---|---|
| 회사 이름, 티커, 고유 제품명, 정확한 날짜, 판단 시점 이후의 모든 것 | 연도, 업종, 규모 구간, 당시 시장 상황 |

- 목적은 회사 맞히기를 막는 것이 아니라 **브랜드 대신 정보를 읽게 하는 것**이다. 역사적 사례는 상황을 보면 회사가 짐작되는 것이 보통이고, 그래도 괜찮다.
- 판단 전에 **"이 회사를 아는 것 같아요"** 체크를 둔다. 아는 판단과 모르는 판단을 일지에서 구분한다. 체크는 판정에 쓰지 않는다.
- 마스킹 검사는 **결과 유출 없음**(판단 시점 이후 정보·수치·사건이 없음)에 집중한다.

### 5.4 카드가 담는 것

- **메타:** 연도(공개), 업종 공개 수준, 규모 구간, 판단 기간(기본 6개월, 3·12개월 허용), 난이도, 카드 버전.
- **판단 전 세 판:** 위 5.1.
- **결과(공개 전에는 아무에게도 보이지 않음):** 회사·티커·실제 날짜, 시작·종료 가격, 기간 수익률, 시장·업종 수익률, 가격 경로(파생 지수 14점).
- **학습 포인트:** 개념 1~2개.
- **출처·버전 기록:** 자료 기준일, 출처 목록, 검토일, 신고 건수, 마지막 수정 이유.

### 5.5 판단 입력

| 단계 | 입력 |
|---|---|
| 기본 | 아는 회사 체크(선택) · **핵심 근거 1개(필수)** · 위험 요인 1개(선택) · **확신도 1~5(필수, 기본값 없음)** · 시장 대비 앞섬/뒤짐 |
| 확장(난이도 4) | 추가 근거 최대 3개, 한 줄 근거, 더 필요한 정보, 판단 무효화 조건 |

- 근거와 확신도를 고르기 전에는 판단(스와이프·버튼)이 열리지 않는다.
- 첫 질문은 언제나 **시장 대비**다. 절대 상승·하락은 시장 흐름에 좌우된다.
- 판단 뒤 2.5초 안에 되돌릴 수 있고, "바로 공개"로 건너뛸 수 있다.

### 5.6 공개

반드시 보여 줄 것: 회사·티커·실제 기간, 회사 수익률, 시장 수익률, **결과 상태(앞섬/뒤짐/비슷함)**, 가격 경로, 내 판단(방향·근거·확신도), 사후에 중요했던 것(이 카드의 학습 포인트), 개념 1개와 확인 문제 1개, 신고 버튼.

> 예) 회사 +4.8% / 시장 +7.1% → 주가는 올랐지만 **시장보다 2.3%p 뒤졌다**.
> 예) 회사 +10.2% / 시장 +9.8% → **비슷했다**. 이 판단은 적중·실패로 세지 않는다.

### 5.7 난이도

| 난이도 | 보이는 정보와 입력 |
|---|---|
| 1 | 각 판의 핵심 숫자만, 근거 1개 + 확신도 + 방향 |
| 2 | 위 + 위험 요인 |
| 3 | 세 판 전체(More 포함) |
| 4 | 위 + 판단 무효화 조건 |
| 5 | (2단계) 역추적 |

입력의 기본 틀(근거·확신도·시장 대비)은 모든 난이도에서 같다. 난이도는 **정보량과 보조 입력**만 바꾼다.

**정보 수준(2026-10-04 추가, D16).** 난이도가 카드의 속성이라면 정보 수준은 **사용자의 설정**이다. 초급 「핵심만」 · 중급 「기본」(기본값) · 고급 「전부」 · 사용자 지정 중 하나를 온보딩에서 고르고 언제든 바꾼다. 세 판은 늘 셋이고(기술적 분석·기본적 분석·당시 상황), 수준은 각 판의 **깊이**만 바꾼다 — 초급은 지수 경로·매출 성장·영업이익률·PER vs 업종·금리·이슈 2개, 고급은 PBR·PSR·순현금·FCF·환율·원자재 메모까지. 깊이 표와 화면은 `02_UX_검토와_화면_변경.md` §7.1. 어느 수준에서 판단했는지는 판단과 함께 남긴다.

## 6. 학습 구조 — 듀오링고에서 들여온 것과 들이지 않은 것

| 들여온 것 | 들이지 않은 것 |
|---|---|
| 개념 트리(네 갈래 20개) | XP, 레벨업 연출 |
| 짧은 일일 세션(카드 3장 + 복습 2개, 5~7분) | 리그·순위 |
| 간격 복습(1·3·7·21일) | 연승 배지, 적중 배지 |
| 연습한 날 스트릭 | 적중률 랭킹, 수익률 비교 |
| 숙련도 4단계(신규·학습 중·복습 필요·이해) | 통합 점수 하나 |
| 수준 선택 온보딩 → 정보 수준(2026-10-04) | 배치 시험·점수 |
| 세션 진행 띠, 화면당 한 동작, 세션 끝 "내일 복습 n개"(2026-10-04) | 하트·보석·스트릭 프리즈 |
| 개념 탭 '길' 보기 — 잠금 없음(2026-10-04) | 마스코트·연승 축하 연출 |

- **세션(오늘):** 그날의 카드 3장을 차례로 풀고, 복습 기한이 된 개념 문제를 2개까지 푼다. 끝나면 "오늘은 여기까지"와 개념 요약. '한 장 더'는 허용하되 기록한다.
- **스트릭:** 세션을 한 날이 이어진 수. 틀려도 끊기지 않는다.
- **복습:** 개념 문제를 맞히면 다음 간격(1→3→7→21일), 틀리면 1일로 돌아간다.
- **일지:** 모든 판단을 시간순으로. 바로 열린다.
- **통계:** 일지 안의 접힌 영역. 20장이 쌓이면 근거별 횟수, 확신도와 결과의 관계를 **글로** 적는다. 큰 숫자 하나로 요약하지 않는다.

## 8. AI 역할과 표시 원칙

### 8.1 역할

| 시점 | 역할 | 보는 것 | 하는 일 |
|---|---|---|---|
| 공개 전 | **질문자** | 세 판 + 사용자의 근거·확신도 | 반문 1개, 놓친 정보 질문 1개. 두 문장 이내. 정답·결과·회사명 언급 금지 |
| 공개 후 | **해설자** | 결과 + 사용자 판단 + 개념 | 사용자 근거와 사후에 중요했던 것을 나란히, 개념 한 문장 연결. 결과를 하나의 원인으로 단정하지 않음 |

- 질문자는 **템플릿 질문 유형 6종** 안에서만 말한다: ① 근거의 반대 증거 묻기 ② 다른 판에서 놓친 숫자 묻기 ③ 시장 대비인지 절대인지 확인 ④ 기간이 바뀌면 판단이 바뀌는지 ⑤ 판단을 무효화할 조건 ⑥ 확신도의 근거.
- AI는 서버가 준 숫자만 말한다(숫자 발화 제한). 문서에 없는 이유를 문서의 말처럼 쓰지 않는다(2단계 역추적에서 인용 제한으로 확장).
- 실존 인물 1인칭 연기는 하지 않는다. 말투(페르소나)는 질문자·해설자의 어조에만 쓴다.

### 8.2 금지

미래 주가 추천·매수·매도 지시, "원래 사야 했다", 결과를 한 원인으로 단정, 한두 문제로 실력 평가, 추론을 사실로 서술.

### 8.3 라벨(문장 단위)

| 칩 | 의미 | 탭하면 |
|---|---|---|
| 📄 출처 | 공시·보도 원문 확인 | 원문 위치·날짜 |
| 🔍 추론 | 당시 자료 기반 AI 해석 | 추론에 쓴 자료 목록 |
| ❓ 불확실 | 근거가 약한 해석 | 반대 해석 |

경고는 카드 하단이 아니라 **추론 문장 옆**에 둔다. 추론 비중이 높은 카드에만 상단 배너.

### 8.4 문구

- 추론 옆: "AI 해석이에요. 공식 발표된 이유는 아니에요."
- 판단 유도(입력 칸과 세트): "AI 해석에 동의하나요? 다르게 본다면 근거를 하나 골라주세요."
- 금지: "~ 때문에 올랐습니다"(단정), "AI 분석 결과 ~"(권위 부여), "참고만 하세요"(효과 없는 관용구).

## 9. 점수·리포트 원칙

- **주가 방향 적중률을 점수로 만들지 않는다.** 큰 숫자 하나, 랭킹, 연승 배지는 없다.
- 결과는 세 상태로 읽고, 비슷함은 적중·실패로 세지 않는다.
- 일지는 바로, 통계는 20장 뒤. 통계는 글로 쓴다: "확신도 5를 준 판단 6번 중 시장보다 앞선 것은 2번이었어요."
- 개념 숙련도만 상태로 보여 준다.

## 10. 데이터 품질·누수 방지

### 10.1 LLM 사후 지식 누수

LLM은 결과를 이미 학습했을 가능성이 높다. 시스템 프롬프트만으로는 막지 못한다.
- 판단 전 텍스트(그때 판)는 LLM 생성 대신 **사람이 템플릿으로** 쓴다.
- 질문자 응답에 **누수 필터**: 판단 시점 이후 날짜·회사명·티커·제품명·결과 수치 사전 검사 + 판정 1회. 하나라도 걸리면 응답을 버리고 안전 문장으로 바꾼다("근거를 하나 더 말해줄래요?"). 걸린 횟수를 기록한다.
- **방향 중립성 시험:** 질문자가 낸 질문 유형이 결과(앞섬/뒤짐)와 상관이 없어야 한다. 카드 30장 × 질문 3회로 확인한다.

### 10.2 카드 생성 체크리스트

- [ ] 판단 시점 이후 정보 없음(세 판 전체)
- [ ] 그때 판 문장에 결과 암시 없음, 날짜는 상대 날짜, 출처 종류 표기
- [ ] 회사명·티커·고유 제품명 없음
- [ ] 흐름 판에 판단 시점 이후 구간 없음
- [ ] 숫자 판에 정정치 없음, 각 수치의 공시 시점 ≤ 판단 시점
- [ ] 결과 수익률에 배당·분할 반영
- [ ] 학습 포인트 지정, 카드 버전 부여, 검토일 기록

### 10.3 신고

공개 화면의 [정보가 이상해요]: 데이터 오류 / 기업 유추 가능 / 중요 정보 누락 / 결과 설명 부정확 / 개념 설명 이해 어려움 / 출처 오류 / AI 추론이 사실처럼 보임 / 기타. `신고 → 검토 → 수정 → 버전 기록 → 재검증`.

## 12. 콘텐츠 계획 — 베타 30장

| 구성 | 장수 | 뜻 |
|---|---|---|
| 미국 대형주·역사적 사례 | 24 | 금리 인상기 성장주, 팬데믹 수혜·피해, 실적 서프라이즈·쇼크, 고밸류에이션 성장, 저평가 함정, 배당주의 횡보, 업종 사이클 |
| 국내 종목 | 6 | 공공데이터로 라이선스가 깨끗한 보조 트랙. 식별이 어렵고 사용자에게 가깝다 |

균형: 앞섬·뒤짐·비슷함 결과를 고르게, 시장 상승기·하락기를 섞고, 성장주·가치주, 호재·악재를 섞는다. 성공 사례만 고르지 않는다. 카드마다 학습 포인트 1~2개를 지정하고 20개 개념이 최소 한 번씩 첫 공개에 나오게 배치한다.

## 13. 범위와 단계

### MVP(베타, 13주)
- 판단 카드 30장(세 판, 근거·확신도 필수, 시장 대비, 세 상태 공개, 개념 1개 + 문제 1개)
- 학습 구조: 개념 20개, 세션(3장 + 복습 2개), 복습 간격, 스트릭, 일지, 통계(20장 뒤)
- AI: 질문자(템플릿 유형 안에서, 누수 필터), 해설자, 문장 라벨
- 신고, 온보딩 3장, 초대 코드 입장

### 2단계
- 펀더멘털 결과 예측 카드("다음 분기 영업이익률이 개선됐을까?" — 주가보다 노이즈가 작아 학습 신호가 깨끗하다)
- 역추적(A등급 카드 우선, 봉인된 AI 가설)
- 난이도 4(무효화 조건), 개인화 복습(반복 취약 개념)

### 3단계
- 소비 If(기회비용) 결합과 개념 사다리(기회비용 → 복리 → 벤치마크 → 변동성 → 분산)
- 교실 모드(학습지 메타포: 교사가 카드 묶음을 배정)
- 가설 분포 공개(동조 효과 검증 뒤)

### 초기 제외
실거래, 종목 추천, 자동 포트폴리오, 수익률·적중률 랭킹, 통합 점수, 현재 보유 종목 추적, 실존 인물 1인칭 AI, 자유 댓글.

## 16. 열린 질문

1. 세 판 중 「그때」 판의 문장 수와 길이는 어디까지가 적당한가(정보 과부하 대 맥락 부족).
2. '비슷함' 경계 ±1%p가 6개월 기간에 적절한가. 3·12개월 카드에서는 달라야 하는가.
3. 질문자 대화가 세션 길이를 얼마나 늘리는가. 카드 3장 중 1장에만 붙일 것인가.
4. 복습 문제가 같은 문항을 반복하면 외우게 된다. 개념당 문제 몇 개가 필요한가.
5. 아는 회사 체크가 판단을 바꾸는가(체크한 뒤 더 확신하는가).
6. 국내 카드 6장이 미국 카드와 한 덱에서 자연스러운가.
7. 공개 출시 때 가격 자료 라이선스 비용은 감당할 수준인가.
