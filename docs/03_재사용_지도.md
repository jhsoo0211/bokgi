# 재사용 지도 — IfSave·연구 자산을 복기 어디에 쓰는가

_개발자용 부록. 경로는 2026-10-03 기준. IfSave는 `~/projects/IfSave`(Spring Boot Java 21 + Next.js 16 + Postgres), 연구는 `~/projects/IfSave-research/research`(Python)._

| 자산 | IfSave 위치 | 복기 모듈 | 방식 | 비고 |

## 2. IfSave → 복기 (가져오지 않음)

| 자산 | 이유 |
|---|---|
| 소비 기록·기회비용 엔진(`OpportunityCalculator`) | 소비 If는 3단계. 순수 계산 클래스라 필요해지면 그때 이식 |
| OCR(`domain/ocr`) | 소비 입력 없음 |
| 시장 수집기(`domain/market/ingest`, egress 가드) | 복기는 실시간 시세를 쓰지 않는다. 카드 자료는 오프라인 제작 |
| 타임캡슐 엔티티(`domain/tradejournal`) | 불변 엔티티·개정 로그 패턴만 참고(판단 기록은 수정 불가) |
| 커뮤니티·배지 | 랭킹·배지 없음 |
| 금융행동 프로필 설문 | 렌즈 추천이 없어져 쓸 곳이 없음 |
| Turnstile·JWT 인증 | 초대 코드 + 쿠키 세션으로 대체 |
| Flyway 마이그레이션 | Prisma 마이그레이션 |

## 5. 주의

- AI 키(NIM·Gemini)를 IfSave 운영과 공유한다. 복기 쪽 일일 호출 상한(예: 300회)을 두고, 초과하면 템플릿 질문으로 폴백한다. 운영 장애 시 복기가 한도를 먹지 않게 한다.
- IfSave 커밋 규칙(서명 금지, 경로별 커밋, 비밀값 검사)은 복기 저장소에서도 같게 둔다.
