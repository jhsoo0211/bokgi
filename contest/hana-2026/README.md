## 차별점의 표현

- **차트·실적·당시 상황을 한 카드에**, 무엇을 근거로 볼지는 사용자가 고른다(차트 / 실적 / 둘 다). 근거 칩마다 어느 판에서 왔는지 데이터에 이미 있다(`content/cards/*.json`의 `evidenceOptions[].panel`).
- **정보는 다 주되, 보고 싶은 것만 남긴다.** 정보 수준(초급·중급·고급·사용자 지정 9묶음)은 구현돼 있고, 판 단위 가리기('차트만'·'실적만')는 제안이다. 결정 기록 D8(렌즈 자기선택 폐지)·D18(세 판은 늘 셋)과 맞추기 위해 기본은 '전부 보임', 가리기는 사용자가 하는 것으로 썼다.
- **듀오링고식**은 학습 흐름(짧은 세션·한 번에 한 동작·간격 복습·개념 길·연습 스트릭)만이고 보상 장치(XP·리그·하트·적중 랭킹)는 없다(D5·D17).
- 판단 리포트(대시보드)는 근거 유형별 결과 **분포·횟수**로만 보여 준다(승률 %·점수 없음, ADR-0002 유지). 판단 데이터의 AI 활용은 별도 동의·가명 처리를 전제로 기대효과에만 쓴다.
- 첫 워딩은 **'투자형 듀오링고'**. '투자 연습'은 모의투자처럼 들려서 쓰지 않는다(메뉴 이름은 '복기', 설명은 '투자 학습'·'판단 훈련'). '모의투자'는 기존 대안 비교·규제 명칭에서만.
- MTS 연결은 **학습 → 실전**: 메인 '복기' 메뉴, 첫 투자 준비, 지표 도움말 → 개념 카드 → **하나증권 자사 콘텐츠로 이어보기**(하나증권V 리서치 포인트·AI 브리핑, 세미나라운지 영상, 70여 개 주제별 리서치 구독, 하나TV 모닝브리프), 주문 화면 근거 메모. 추천·예측·모의투자는 하지 않는다.
- 트랙 01(더 편리한 금융) 분야 대응: 새로운 손님서비스(투자습관 형성) · MTS 이용 편의(세 판 = 하나증권V 차트·재무·리서치 메뉴 순서라 연습하며 메뉴 흐름과 내용을 스스로 익힘) · AI 손님지원(결과 해설·'틀렸다면 왜'에서 하나Q로 이어 묻기, 맞춤 알림) · 투자 입문자 맞춤.
- 호칭(손님·사용자)은 최대한 쓰지 않는다. 문장은 주어 없이, 필요하면 '초보 투자자'·'청년 투자자'. '손님'은 가이드 항목명(1-1·2-2·3-1 머리말, 보충자료 '기대효과 · 손님')에만.
- 본문은 다른 AI가 쓴 초안을 바탕으로 보완했다: 출처 바로잡기, 근거 없는 경쟁사 비교(KB·신한)·과장 표현 삭제, 확인 안 된 '1분 쇼츠' → '영상'.
