# IfSave Design System — Worksheet(학습지)

직접 판단해보며 배우는 금융. IfSave는 마스킹된 실제 사례를 두고 사용자가 먼저 판단하고, 결과와 근거를 확인하며 금융개념을 배우는 학습 서비스다. 이 시스템은 그 화면들을 만드는 공통 언어다.

방향은 **B · 학습지(worksheet)** 로 확정했다. 흰 종이에 굵은 제목, 괘선과 각진 답란, 선택은 빨간 펜 동그라미, 결과는 도장. 장식은 없다.
토큰은 `design/tokens.json`(원본)과 `design/tokens.css`(CSS 변수·타입 클래스), 컴포넌트는 `design/components.css`에 있다. 다른 다섯 방향의 토큰이 필요하면 `reference/design-options-all.html`을 참고한다.

## 1. 원칙

1. **판단 전에는 결과색이 없다.** `up`·`down`은 결과 공개 화면에서 처음 나타난다. 판단 전 화면의 유일한 강조는 `action` 하나다.
2. **상승은 빨강, 하락은 파랑.** 국내 시장 관행을 따른다. 미국식(초록/빨강)으로 바꾸지 않는다.
3. **근거는 문장 옆에 붙는다.** AI 문장은 📄 출처 / 🔍 추론 / ❓ 불확실 라벨을 문장 단위로 단다. 카드 하단의 면책 한 줄로 대신하지 않는다.
4. **정답 맞히기가 아니라 근거 남기기.** 적중률을 크게 보여주는 화면, 랭킹, 연승 배지는 만들지 않는다. 숫자보다 근거·확신도·개념이 먼저다.
5. **한 화면에 강조 한 곳.** `action`은 화면당 한 요소에만. 나머지는 `ink-500`으로 눌러둔다.
6. **흐린 그림자는 없다.** 그림자는 단색 오프셋뿐이다(stack의 두께, sticky의 종이 한 겹, calculator의 키 아랫면). 구조는 테두리와 여백으로 만든다.

## 2. 색

의미 이름만 쓴다. 세 테마가 같은 이름을 공유하므로 컴포넌트는 테마를 몰라도 된다.

| 역할 | 토큰 | 규칙 |
|---|---|---|
| 바탕 3단 | `bg-000` `bg-100` `bg-200` | 화면 → 카드 → 눌림/뒤 카드 |
| 글자 3단 | `ink-900` `ink-500` `ink-200` | 본문 → 보조 → 괘선·테두리 |
| 판단 강조 | `action` `action-ink` | 주 판단 버튼, 진행 바 |
| 선택 | `select` `select-ink` | 선택된 칩: 빨간 펜 링(칠하지 않음). 선택된 렌즈: 잉크로 채움 |
| 시장 결과 | `up` `down` | 결과 화면 전용 |
| 결과 패널 | `board` 계열 | 선택 사항. 잉크색 판이 필요할 때만 |
| 근거 라벨 | `label-source` `label-inference` `label-uncertain` | 테두리·글자만, 바탕은 칠하지 않음 |
| 포커스 | `focus` | 2px 링, 모든 테마 3:1 이상 |

대비: `ink-900`/`bg-000` 15.9:1, `ink-500`/`bg-000` 5.2:1, `up` 5.0:1, `down` 6.0:1.

## 3. 글자

서체는 **Pretendard** 하나(`design/fonts/` 400·500·600·700). 제목 700(자간 −1%), 본문 400(줄간격 22px), 숫자 700에 `font-feature-settings: "tnum"`. 스케일은 `.b-display`(26/32) `.b-title`(18/24) `.b-body`(14/22) `.b-caption`(12/18) `.b-num`(15/20). 본문 줄 길이 40자 이내. 음수 부호는 U+2212(−). 300 이하 굵기는 쓰지 않는다.

## 4. 간격·반경·테두리

- 간격 6단 `--space-1`(4) ~ `--space-6`(32). 카드 안쪽 12/16, 카드 사이 12, 섹션 사이 24.
- 반경: 답란·칩·버튼은 `--radius-0`, 일반 모서리 `--radius-4`, 라벨·진행 바·소인은 `--radius-pill`.
- 테두리: 답란·괘선 1.5px(`--border-rule`), 포커스 링과 펜 링 2px(`--border-bold`). 괘선은 `1px dotted #9a9890`.
- 그림자 없음.

## 5. 상호작용 — 스와이프 구조

판단 카드의 핵심 동작이다. 상세는 `components/SwipeCard/README.md`.

```
카드 보기 → 근거 칩 1개 선택(필수) → 확신도(기본 3) → 좌우 스와이프 → 이탈 → 결과 공개 → 개념 → 다음 카드
```

- 스택 3장(현재 + 뒤 2장 peek). 뒤 카드는 터치를 받지 않는다.
- 오른쪽 = 시장보다 잘했다(상회), 왼쪽 = 못했다(하회). 위·아래 스와이프에는 기능이 없다. 보류는 별도 버튼.
- 이탈 임계 `max(80px, 너비×0.30)` 또는 속도 0.6px/ms. 회전 ±12°.
- **게이트:** 근거를 고르기 전에는 임계를 넘어도 이탈하지 않고 되돌아온다. 칩 영역이 흔들리고 힌트가 바뀐다.
- **되돌리기:** 이탈 후 2.5초 토스트. 기록 삭제 후 같은 카드로 복귀.
- **대체 입력:** 버튼 2개와 키보드 ←→는 항상 있다. `prefers-reduced-motion`이면 이탈 애니메이션 없이 즉시 전환.
- **기록:** 방향, 근거, 거리, 시간, 속도, 방향 전환 횟수(망설임). 스와이프 거리로 확신도를 추정하지 않는다.
- 결과 공개는 카드가 이탈한 뒤 별도 화면으로 온다. 판단 전 카드 뒷면에 결과를 두어 미리 보이게 하지 않는다.

## 6. 컴포넌트 (design/components.css)

| 클래스 | 쓰는 곳 |
|---|---|
| `.ds-card` | 답란(카드). 잉크 1.5px 테두리, 각진 모서리 |
| `.ds-kv` | 항목 행. 점선 괘선 |
| `.ds-chip[aria-pressed]` | 근거·위험·가설 칩. 선택은 빨간 펜 링 |
| `.ds-lens` | 차트/재무/복합 세그먼트 |
| `.ds-conf` | 확신도 1~5 |
| `.ds-btn`, `.ds-btn--primary` | 버튼. 주 버튼은 잉크로 채움 |
| `.ds-label--source/inference/uncertain` | 📄 🔍 ❓ 문장 라벨 |
| `.ds-stamp`, `.ds-stamp--ok` | 채점 도장 |
| `.ds-postmark` | 역추적 시점 소인 |
| `.ds-bar` | 진행 바 |
| `.ds-nums` | 결과 수치 3칸 |
| `.ds-bubble--ai/me` | 말풍선 |
| `SwipeStack` (app/js/swipe.js) | 스와이프 카드 스택. 규칙은 §5 |

아직 없는 것: 개념 카드·퀴즈·신고 시트는 app/css/app.css에 화면 스타일로만 있다. 재사용되기 시작하면 components.css로 올린다.

## 7. 쓰는 법

1. `design/tokens.css` → `design/components.css` → 화면 CSS 순서로 불러온다.
2. `<html data-theme="worksheet">` 를 둔다(지금은 한 테마지만, 다른 테마를 되살릴 때를 위해).
3. 컴포넌트는 의미 색 토큰(`--bg-000`, `--ink-900`, `--action` …)과 `--ds-*`만 쓴다.
4. 판단 전 화면에서 `--up` `--down`을 쓰는 코드는 리뷰에서 막는다.

## 8. 하지 말 것

- 파랑–보라 그라데이션, 흐린 회색 그림자, 왼쪽 색 테두리 카드.
- 대문자 라벨, 제목 한 단어만 색 바꾸기.
- 실존 투자자의 사진·초상·1인칭 말투.
- 적중률·수익률을 큰 숫자 한 개로 보여주는 히어로.
