_작성일: 2026-09-30 · 이전 버전: v0.1 (2026-09-30)_

>

## 1. 한 줄 정의

**내 소비와 실제 시장 사례를 두고 직접 판단하고, 결과와 근거를 확인하며 금융을 배우는 AI 금융 학습 서비스**

공통 키워드: **"직접 판단해보며 배우는 금융"**

---

## 2. 문제 인식

1. **금융생활은 시작됐지만 금융이해력은 따라오지 못한다.** 정보를 읽고 자기 판단으로 연결하는 경험이 부족하다.
2. **지출 관리 관심이 장기 재무관리로 이어지지 않는다.** 소비 기록이 기회비용·장기 목표 이해로 연결되지 않는다.
3. **기존 금융교육은 수동적이다.** `콘텐츠 읽기 → 퀴즈 → 다음 콘텐츠` 구조에 머문다.
4. **"대가 포트폴리오"는 따라 사기 소재로만 소비된다.** 무엇을 샀는지는 쉽게 보지만, 왜 그 시점에 그 선택을 했는지 훈련하는 경험은 없다.

IfSave는 이를 `실제 사례 → 내가 먼저 판단 → 결과·근거 확인 → 개념 학습 → 다음 사례에 적용`으로 바꾼다.

## 3. 시장 조사와 차별점

### 3.1 유사 서비스 지도

| 유형 | 사례 | 겹치는 점 | IfSave와의 차이 |
|---|---|---|---|
| 가려진 차트 방향 맞히기 | ChartGame, Chart Challenge, Chart Guess, 차트야 놀자 | 마스킹 → 판단 → 공개 | 가격 차트·기술적 패턴만 다룸 |
| 스와이프 종목 탐색 | Tickup, Prophit | 스와이프 + 학습 팁 | 현재 종목 '관심·발견' 용도 |
| 금융 마이크로러닝 | Zogo, Fingo, Finelo | 개념 학습·게이미피케이션 | 콘텐츠 → 퀴즈 구조 |
| 소비 기회비용 계산 | Skip or Buy, OCC | 소비를 투자로 환산 | 고정 수익률 가정 계산기 |
| 대가 포트폴리오 추적 | WhaleWisdom, Stockcircle, 치킨스탁 | 기관 보유 종목 공개 | 무엇을 샀나만 보여줌 |
| AI 대가 챗봇 | BuffettBot, KeepRule, The Warren AI | 투자자 철학 기반 AI 대화 | 질문 응답 도구, 판단 훈련 없음 |
| 익명 재무 판단 교육 | Ivey 케이스 'The Game of Financial Ratios' | 기업명 가린 재무정보 판단 | 경영대 수업용, 앱 아님 |

### 3.2 차별 지점

검색 범위 안에서 아래 조합을 하나의 소비자 서비스로 구현한 사례는 확인되지 않았다.

1. 가격뿐 아니라 **펀더멘털·포트폴리오 결정**까지 판단 소재로 사용
2. 결과를 **시장 대비**로 공개
3. 판단 **근거·확신도**를 기록하고 적중률 대신 판단의 질을 추적
4. 결과 뒤 **금융개념을 연결**하고 다음 판단에서 재사용
5. **렌즈별 판단 스타일 비교** (차트형인가 재무형인가)
6. 검증된 투자자 결정의 **"왜"를 역추적**하고, 근거 등급을 명시

> 경쟁 우위는 '마스킹'이 아니라 **무엇을 가리고, 무엇을 판단하게 하고, 무엇을 가르치느냐**에 있다.

## 4. 서비스 구조 개요

| 모드 | 소재 | 핵심 질문 | 도입 시점 |
|---|---|---|---|
| **소비 If** | 사용자의 실제 소비 | "이 돈의 다른 가능성은?" | MVP (범위 결정 필요, §14) |
| **판단 카드** | 마스킹된 과거 기업·시장 사례 | "이후 시장 대비 어땠을까?" | MVP 핵심 |
| **역추적** | 검증된 투자자·기관의 과거 결정 | "왜 이렇게 투자했을까?" | 2단계 |

---

## 5. 공통 학습 루프

`Observe → Judge → Reveal → Learn → Apply → Reflect`

1. **Observe:** 실제 소비 또는 판단 시점까지의 정보만 본다.
2. **Judge:** 사용자가 먼저 판단하고 근거를 고른다.
3. **Reveal:** 실제 결과(와 공개된 근거)를 확인한다.
4. **Learn:** 자신의 판단과 관련된 개념 1~2개를 배운다.
5. **Apply:** 다른 사례에서 같은 개념을 다시 쓴다.
6. **Reflect:** 근거·확신도·오류 패턴의 변화를 본다.

## 6. 소비 If 모드

### 흐름
1. 소비 기록
2. 같은 금액의 대안가치 확인 (실제 시장·금융상품 기준)
3. 기회비용 관련 개념 학습
4. 소비 만족도·필요도 회고
5. 다음 소비에서 이전 학습 상기

### 개념
기회비용, 현재가치/미래가치, 복리, 저축과 투자, 확정수익/변동수익, 고정비/변동비, 예산과 장기 목표

### 원칙
- 기회비용을 "쓰지 말았어야 했다"로 쓰지 않는다. **같은 돈의 다른 가능성**을 보여준다.
- 하락장에는 비교 대상을 안전자산으로 바꾸는 벤치마크 스위칭을 유지한다.

### 투자 카드와의 연결 (개념 사다리)
`기회비용 → 복리 → 벤치마크 → 변동성 → 분산`
소비에서 배운 개념이 판단 카드의 첫 개념으로 이어지도록 설계한다.

## 7. 판단 카드 모드 — 렌즈형

### 7.1 렌즈 구성

하나의 마스킹 사례에 차트 블록과 재무 블록을 모두 저장하고, 사용자가 판단 렌즈를 고른다.

| 렌즈 | 제공 정보 | 주요 개념 |
|---|---|---|
| 차트 | 정규화 가격, 거래량, 시장·업종 흐름 | 추세, 모멘텀, 변동성, 평균회귀, **기저확률·노이즈** |
| 재무 | Core Card (성장·수익성·밸류에이션·재무건전성) | PER/PBR, 이익의 질, 현금흐름, 부채 |
| 복합 | 두 블록 모두 | 성장과 밸류에이션, 모멘텀과 펀더멘털의 충돌 |

**렌즈형을 택한 이유**
- 콘텐츠를 한 번 만들어 세 방식으로 사용 (제작 비용 절감)
- 렌즈별 적중·확신도 보정을 비교해 **자기 판단 스타일**을 보여줄 수 있음
- 정보 유형을 연구 변수로 그대로 사용 가능 (§15)

**렌즈 운영 규칙**
- 같은 사례를 서로 다른 렌즈로 연달아 제시하지 않는다 (기억 오염 방지).
- 차트 렌즈는 패턴을 정답처럼 가르치지 않는다. 기저확률과 노이즈 개념을 반드시 포함한다.

### 7.2 카드 스키마

```
case_id
meta: 판단 시점(마스킹), 판단 기간, 업종 공개 수준, 규모 구간
chart_block: 정규화 가격, 거래량, 시장/업종 수익률
fundamental_block:
  growth: 매출 성장률, 영업이익률 추이, EPS 성장률, 가이던스
  valuation: PER, 업종 중앙값, PBR, PSR
  health: 부채비율, 순현금/순부채, 영업현금흐름, FCF, 이자보상배율
  context: 기준금리, 환율·원자재, 산업 이벤트(날짜·출처 포함)
outcome: 기업 수익률, 벤치마크 수익률, 업종 수익률, 가격 경로
learning_points: 사전 지정 개념 1개 이상
version_meta: card_version, data_cutoff_date, source_version, generated_at, reviewed_at, report_count, last_modified_reason
```

### 7.3 정보 제공 원칙

1. 판단 시점에 알 수 있었던 정보만 제공한다.
2. 모든 카드에 동일한 스키마를 사용한다.
3. Core / More Info를 분리한다.
4. 데이터가 없으면 `데이터 없음 / 해당 시점 기준 미공개`로 표시한다.
5. 뉴스·이벤트는 판단 시점 이전 사실만, 날짜·출처와 함께 **템플릿으로** 작성한다 (§11 LLM 누수 참조).

### 7.4 판단 입력

| 단계 | 입력 |
|---|---|
| MVP | 렌즈 선택, **가장 중요하게 본 정보 1개(필수)**, 시장 대비 상회/하회, 확신도 1~5 |
| 확장 | 최대 3개 근거, 가장 큰 위험요인, 한 줄 근거, 추가로 필요한 정보, 판단 무효화 조건 |

- 근거 선택 뒤에 스와이프가 활성화되도록 한다 (즉흥 판단 방지).
- 첫 질문은 **시장 대비**. 절대 상승·하락은 시장 흐름(베타)에 좌우된다.
- 판단 기간 기본값: 3~12개월 (P0에서 확정).

### 7.5 결과 공개

반드시 보여줄 것: 기업명, 티커, 실제 날짜, 시작·종료 가격, 기간 수익률, 벤치마크·업종 수익률, 실제 가격 경로

> 예) 기업 수익률 +4.8% / S&P 500 +7.1% → 주가는 올랐지만 시장 대비 -2.3%p

### 7.6 결과 뒤 개념 학습

- AI는 "주가가 왜 움직였는지"를 단정하지 않는다.
- "이번 사례에서 다시 볼 개념" 1~2개와 확인 문제 1~3개를 제공한다.
- 개념은 사용자가 고른 근거와 카드의 사전 지정 학습 포인트를 기준으로 고른다.

### 7.7 난이도

| Level | 내용 |
|---|---|
| 1 | 단일 렌즈, 방향 판단 |
| 2 | 가장 중요한 정보·가장 위험한 정보 선택 |
| 3 | 시장 대비 상대 판단 + 확신도 |
| 4 | 추가 확인 데이터, 판단 무효화 조건 |
| 5 | **역추적 모드** (포트폴리오·자산배분 관점) |

### 7.8 초기 카드 데이터셋

- 카드 수보다 품질 통제 우선: 8~12개 수작업
- 상승·하락 사례, 시장 상승기·하락기, 성장주·가치주, 실적 호재·악재를 균형 있게 구성
- 미국 대형주는 식별이 쉬우므로 업종 공개 수준을 조절하거나 중형주·국내 종목을 섞는다.
- 국내 종목은 DART 공시일 기준 시점 데이터를 쓰고, 이후 정정 수치를 배제한다.

| 카드 | 학습 포인트 |
|---|---|
| A | 높은 성장률 ≠ 무조건 좋은 투자 |
| B | 실적 개선과 높은 밸류에이션 |
| C | 금리와 성장주 |
| D | 매출 성장과 현금흐름의 차이 |
| E | 절대수익과 시장 대비 성과 |
| F | 최근성과 편향 |
| G | 높은 부채와 경기 민감도 |
| H | 분산과 개별 종목 위험 |

### 7.9 확장 카드 유형 (검토)

**펀더멘털 결과 예측 카드**: "다음 분기 영업이익률이 개선됐을까?"
주가 방향보다 노이즈가 작아 학습 신호가 깨끗하다.

## 8. 역추적 모드 — "왜 이렇게 투자했을까?"

### 8.1 목적

검증된 투자자·기관의 과거 결정을 보고 이유를 추론하며 **자산배분, 리밸런싱, 분산, 운용 제약, 투자 원칙**을 배운다.
대형 기관의 결정은 시장 전망보다 **규칙·제약**에서 나오는 경우가 많다는 점을 가르치는 것이 핵심 가치다.

### 8.2 근거 등급

| 등급 | 기준 | 예시 소스 | 표현 |
|---|---|---|---|
| **A. 문서 확인** | 결정 이유가 문서에 명시됨 | 버크셔 주주서한·주총, 미국 13D '거래 목적', 한국 5% 대량보유 '보유 목적', 펀드 운용서한, Value Investors Club 투자 논리, 국민연금 자산배분 계획 | "공개된 이유" |
| **B. 정황 추론** | 당시 데이터 + 투자자의 공개 원칙으로 추론 | 13F 보유 변화 + 당시 밸류에이션·금리 | "가능한 해석 2~3개" |
| **C. 근거 부족** | 둘 다 없음 | — | 카드로 쓰지 않음 |

**소스별 한계**
- 13F: 분기 종료 후 45일 이내 공시, 미국 롱 포지션만, 이유 없음 → 문제 재료로만 사용
- 버크셔: 대형 결정 일부만 서한에서 설명. 투자 매니저가 결정한 종목은 근거가 없는 경우가 많음
- 국민연금: 종목별 매수 이유 비공개. 월별 포트폴리오, 연말 종목별 현황(다음 해 3분기 공시), 자산배분 방향은 공개 → **자산배분 문제 전용**
- Value Investors Club: 매수 시점 논리 전문 + 이후 결과 확인 가능, 45일 지연 공개. **상업적 이용 조건 확인 필요**

### 8.3 카드 흐름

1. 투자자를 **"기관 X"로 마스킹**하고 결정만 제시 (신규 편입·비중 변화, 업종, 당시 재무)
2. 사용자 가설 선택 + 근거 1개 (필수)
   - 가설 보기: 밸류에이션 판단 / 금리 대응 / 리밸런싱 규칙 / 유동성·규모 제약 / 규제·의무 / 기타
3. AI 질문자와 2~3턴 대화
4. 봉인된 AI 가설과 사용자 가설을 동시에 공개
5. A등급: 실제 근거 문서 요약 대조 / B등급: 해석 2~3개와 각 반증 조건
6. 이후 성과·벤치마크 대비 결과
7. 관련 개념 연결
8. 투자자 이름 공개

### 8.4 AI 참가자 봉인

사후 서사 오류(결과를 알고 모든 결정을 그럴듯하게 설명하는 문제)를 막기 위한 장치다.

1. AI에게 판단 시점 데이터만 주고 가설을 생성해 **봉인**한다 (기존 타임캡슐 구조 재활용).
2. 사용자 가설 제출 후 동시 공개한다.
3. A등급 카드에서는 사용자와 AI 중 누가 실제 근거에 더 가까웠는지 보여준다.
4. AI가 틀리는 장면을 그대로 노출해 AI 추론에 대한 과신을 줄인다.

### 8.5 가설의 질 평가 (정답이 없는 카드)

| 기준 | 질문 |
|---|---|
| 근거 일관성 | 당시 데이터와 맞는가 |
| 원칙 일관성 | 해당 투자자가 공개한 투자 원칙과 맞는가 |
| 반증 가능성 | 틀렸음을 확인할 조건을 적었는가 |

### 8.6 생존 편향 방지

- 성공 사례만 고르지 않는다. 실패·번복 결정을 일정 비율 포함한다.
- 현재 보유 현황은 다루지 않는다. **종료된 과거 결정만** 사용한다 (따라 사기 오인 방지).

## 9. AI 역할과 표시 원칙

### 9.1 역할

| 시점 | 역할 | 접근 데이터 | 하는 일 |
|---|---|---|---|
| 공개 전 | **질문자** | 판단 시점 카드 데이터만 | 반문, 근거 요구, 놓친 정보 질문. 정답 언급 금지 |
| 공개 전 | **참가자** | 판단 시점 데이터만 | 가설 생성 후 봉인 |
| 공개 후 | **해설자** | 근거 문서 + 결과 데이터 | 사용자 가설과 실제 논리 비교, 개념 연결 |

- 서버 계산 숫자만 말하는 기존 원칙을 **인용문까지 확장**한다. 문서에 없는 이유를 문서의 말처럼 쓰지 않는다.
- 실존 인물 1인칭 연기("나는 버핏이다")는 하지 않는다. 기존 페르소나(할머니, 펀드매니저 등)를 질문자·해설자 말투로 재활용한다.

### 9.2 AI 금지 사항

- 미래 주가 추천, 매수·매도 지시
- "이 종목은 원래 사야 했다"
- 결과를 하나의 원인으로 단정
- 한두 문제로 사용자 실력 평가
- 추론을 사실로 서술 ("버크셔는 ~ 때문에 샀다")

### 9.3 라벨 체계 (문장 단위)

| 칩 | 의미 | 탭하면 |
|---|---|---|
| 📄 출처 | 서한·공시 원문 확인 | 원문 위치·날짜 |
| 🔍 추론 | 당시 데이터 기반 AI 해석 | 추론에 쓴 데이터 목록 |
| ❓ 불확실 | 근거가 약한 해석 | 반대 해석 보기 |

- 경고는 카드 하단이 아니라 **추론 문장 바로 옆**에 둔다.
- 추론 비중이 높은 카드에만 상단 배너를 추가한다.
- 판단 유도 문구 뒤에는 **입력 칸(동의/반대 + 근거 1개)**을 붙인다.

### 9.4 문구 가이드

**추론 문장 옆**
- "AI 해석이에요. 공식 발표된 이유는 아니에요."
- "공개 자료를 바탕으로 한 추측이에요."

**상단 배너**
- "이 카드에는 공개된 투자 이유가 없어요. AI가 당시 자료로 추론한 내용이니, 정답이 아니라 하나의 관점으로 봐주세요."

**판단 유도 (입력 칸과 세트)**
- "AI 해석에 동의하나요? 다르게 본다면 근거를 하나 골라주세요."
- "당신이 이 기관의 운용역이었다면 같은 선택을 했을까요?"
- "이 해석이 틀렸다면, 어떤 데이터가 그걸 보여줄까요?"

**페르소나 버전**
- 할머니: "이건 내 짐작이여. 버핏이 나한테 전화해서 알려준 거 아니여. 니 생각은 어떤디?"
- 펀드매니저: "제 추론입니다. 반박 환영합니다. 근거 가져오세요."

**금지 표현**
- "~ 때문에 샀습니다" (추론을 사실처럼 단정)
- "AI 분석 결과, ~가 이유입니다" (권위 부여)
- "참고만 하세요" (효과 없는 관용구)

## 10. 점수·리포트 원칙

- **주가 방향 적중률을 핵심 점수로 만들지 않는다.**
- 여러 지표를 나눠 보여준다: 결과 방향, 근거 구체성, 위험요인 확인, 확신도-적중 차이, 개념 재사용
- 렌즈별 비교: "차트 렌즈 적중 52%·확신 과잉 / 재무 렌즈 적중 58%·확신 적정"
- 확신도 보정 리포트는 **누적 카드 수 기준(예: 50장)**을 넘은 뒤에만 공개한다.
- 개념 숙련도: 신규 / 학습 중 / 복습 필요 / 이해

## 11. 데이터 품질·누수 방지

### 11.1 마스킹 정책

| 반드시 | 선택 (난이도별) |
|---|---|
| 기업명, 티커, 판단 시점 이후 데이터·기사·실적·컨센서스 변화, 역추적 모드의 투자자명 | 정확한 연도, 국가, 세부 업종, 시가총액 |

목적: 회사 맞히기를 어렵게 하는 것이 아니라 **브랜드·사전지식 대신 제공된 정보를 읽게 하는 것**

### 11.2 LLM 사후 지식 누수 (신규)

LLM은 결과를 이미 학습했을 가능성이 높아, 시스템 프롬프트만으로는 누수를 막지 못한다.

- 판단 전 텍스트(뉴스·이벤트 요약)는 LLM 생성 대신 **템플릿**으로 작성
- 공개 전 AI 대화 응답에 **사후 정보 필터** 적용 (판단 시점 이후 날짜·수치·사건 탐지)
- AI 봉인 가설도 동일 필터 통과 후 저장

### 11.3 카드 생성 체크리스트

- [ ] 결과 기간 이후 정보 미포함
- [ ] 기사·요약에 결과 암시 없음
- [ ] 고유 제품명 등 직접 식별 단서 없음
- [ ] 이후 주가가 포함된 차트 미사용
- [ ] 이후 실적 정정치 미포함
- [ ] 데이터 기준일 명시
- [ ] 동일 생성 규칙 적용
- [ ] (역추적) 근거 등급 지정 및 문장별 라벨 부착

### 11.4 사용자 오류 신고

[정보가 이상해요] 버튼: 데이터 오류 / 기업 유추 가능 / 중요 정보 누락 / 결과 설명 부정확 / 개념 설명 이해 어려움 / 출처 오류 / **AI 추론이 사실처럼 보임** / 기타

`신고 → 검토 → 수정 → 버전 기록 → 재검증`
연구 데이터에는 사용한 카드 버전을 함께 저장한다.

## 14. MVP 범위와 단계

### MVP (1단계)
- **판단 카드**: 렌즈 2종(차트·재무), 근거 1개 필수, 시장 대비 판단, 확신도, 결과 공개, 개념 1~2개, 확인 문제
- **AI**: 공개 전 질문자(제한 모드), 공개 후 해설자
- **라벨·문구**: 출처/추론 칩, 판단 유도 문구
- **피드백**: 오류 신고, 자유 의견
- **소비 If**: 포함 여부 결정 필요
  - 권장안: 투자 카드로 차별점을 먼저 검증하고, 소비 If는 개념 사다리 연결과 함께 2단계에서 결합

### 2단계
- 복합 렌즈, 역추적 모드(A등급 카드 우선), AI 참가자 봉인, 소비 If 결합, 가설 분포 공개

### 3단계
- 역추적 B등급 카드, 펀더멘털 결과 예측 카드, 개인화 복습, B2B 교육 모듈화

### 초기 제외
실거래, 종목 추천, 자동 포트폴리오, 수익률·적중률 랭킹, 과도한 기술적 지표, 통합 점수, 현재 보유 종목 추적, 실존 인물 1인칭 AI

## 15. 연구 연결 (드림학기)

연구와 제품의 목적은 구분한다. 연구는 **어떤 정보·피드백이 판단 과정에 어떤 영향을 주는지** 측정한다.

| AI 대화 | 질문자 대화 유무 → 근거 구체성·확신도 보정 |
| 피드백 방식 | 결과만 / 결과 + 개념 / 결과 + 개념 + AI 비교 |

참고 연구: 익명화·표준화한 재무제표로 LLM이 이익 방향을 예측한 Kim·Muhn·Nikolaev(2024)

## 최종 핵심

IfSave의 목표는 주가를 잘 맞히게 만드는 것이 아니다.

> **실제 금융정보를 읽고, 자기 판단 근거를 세우고, 결과와 근거를 확인해 부족한 개념을 배우고, 다음 판단에서 다시 써보게 만드는 것**

- 소비에서는 **기회비용**을 체감하고,
- 판단 카드에서는 **렌즈별로 금융정보를 해석**하는 법을 연습하고,
- 역추적에서는 **검증된 투자자의 사고**를 가설로 재구성한다.
